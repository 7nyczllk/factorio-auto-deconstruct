## 📖 About

🔹 **Factorio — Auto Deconstruct** is a powerful tool built to help you automatically mark empty miners and depleted ore patches for deconstruction in Factorio. When an ore patch runs dry, Auto Deconstruct marks all associated mining drills and power poles for removal.

🔸 Whether you're a seasoned professional or just getting started, **Factorio — Auto Deconstruct** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Factorio modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Empty Mine Detection | Detects when ore patches are exhausted and marks miners for removal |
| Infrastructure Cleanup | Optionally marks nearby poles, belts, and inserters for deconstruction |
| Alert System | Sends map alerts when sites are marked for cleanup |
| Configurable Delay | Set a delay before marking so miners can fully drain remaining ore |
